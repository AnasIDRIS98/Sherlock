# Overview

This repository documents my investigations while working through the **Sherlock** challenges on Hack The Box.

The goal is **not** to publish challenge solutions, but to document the investigation process, analytical reasoning, and forensic methodology used to reach each conclusion.

Each report is written as if it were part of a real incident investigation, emphasizing evidence over assumptions.

---

# Methodology

Each investigation follows a consistent structure:

- Executive Summary
- Environment
- Evidence Collection
- Timeline Analysis
- Technical Findings
- Hypothesis Validation
- Production Considerations
- Lessons Learned

The emphasis is always on **why** a conclusion was reached—not simply **what** the answer was.
